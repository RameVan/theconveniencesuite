Turndown

Turns down cookie banners for you. It recognises the big consent platforms, finds "Reject all" in ten languages, and switches off every vendor and legitimate-interest toggle when a site hides them behind settings.

  • 20+ consent platforms
  • Refuses legitimate interest
  • Per-site on/off
v1.1.0 · Chrome, Edge, Brave
Download
How to install
  1. Unzip the download somewhere it can stay.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.
  4. Pin it to see the ✓ badge whenever it handles a banner.

PantryPip

A food assistant that keeps your pantry up to date with almost no effort. Snap a receipt, say "I finished the milk", tap "Cooked it". It plans meals, writes the shopping list and learns how fast you use things.

  • Receipt scanning
  • Smart shopping list
  • Works offline as a PWA
v0.1.0 · EN / NL
Try it Android
Install it on your phone or computer

Open Try it, create an account, then:

  1. iPhone / iPad: in Safari tap Share → Add to Home Screen.
  2. Android: download the Android app and open it (allow installing from your browser when asked), or in Chrome tap ⋮ → Install app.
  3. Windows / Mac: in Chrome or Edge click the install icon in the address bar.

It opens full screen with its own icon. This is a shared test copy: your pantry is private to your account, but don't store anything you'd mind losing.

Run your own copy
  1. Install Node.js 24 or newer, then download and unzip the source.
  2. In that folder run npm install, then npm run build.
  3. Run npm start and open http://127.0.0.1:8787.
  4. For real use start with SEED_DEMO=0 to skip the demo household. On iPhone, see docs/IPHONE.md and add it to your home screen.
