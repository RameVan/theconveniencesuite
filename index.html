PantryPip

A food assistant that keeps your pantry up to date with almost no effort. Snap a receipt, say "I finished the milk", tap "Cooked it". It plans meals, writes the shopping list and learns how fast you use things.

  • Receipt scanning
  • Smart shopping list
  • Works offline as a PWA
v0.1.0 · EN / NL
Try it Android
Install it on your phone or computer

Open Try it, create an account, then:

  1. iPhone / iPad: in Safari tap Share → Add to Home Screen.
  2. Android: download the Android app and open it (allow installing from your browser when asked), or in Chrome tap ⋮ → Install app.
  3. Windows / Mac: in Chrome or Edge click the install icon in the address bar.

It opens full screen with its own icon. This is a shared test copy: your pantry is private to your account, but don't store anything you'd mind losing.

Run your own copy
  1. Install Node.js 24 or newer, then download and unzip the source.
  2. In that folder run npm install, then npm run build.
  3. Run npm start and open http://127.0.0.1:8787.
  4. For real use start with SEED_DEMO=0 to skip the demo household. On iPhone, see docs/IPHONE.md and add it to your home screen.

How to start it
  1. Download OptOut-0.1.13.exe and double-click it. Nothing is installed.

TwelveVolt FuseBox

Makes an ordinary 12-way blade fuse box smart. Two identical comb boards slide in beside the fuses, one per side, and each finger is held down by the fuse box's own terminal screw. Every channel then measures its own current, voltage, power and energy, and can be switched on and off from Home Assistant.

  • 12 channels · 2 boards of 6
  • Measured per channel
  • Each board its own device
  • ESPHome · Home Assistant
  • BaseA standard 12-way blade fuse box. It keeps doing the fusing, the + feed and the − bus; the boards add switching and measuring on top.
  • BoardsOne board design, fitted twice: the right side uses the same board turned around. Each has six fingers that rest on the fuse terminals, so the current goes straight from the fuse into the board.
  • Per channelA shunt and INA226 measuring chip, and a BTS50015 smart switch with short-circuit and over-temperature shut-off. A jumper sets the power-up state; channels start off.
  • ControlAn ESP32-S3 on each board runs ESPHome, so both boards are separate Home Assistant devices. USB-C for setup; the firmware switches off the heaviest load first if the board runs hot.
  • OutputsLever clamps for wires with ferrules up to 6 mm²; channels are designed for loads up to 15 A.
  • EnclosureA 3D-printed case over the box and both boards, with a label spot per fuse.
